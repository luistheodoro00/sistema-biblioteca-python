

# Sistema de Biblioteca em Python

Sistema de gerenciamento de biblioteca desenvolvido em Python com foco em boas práticas de programação.

## Funcionalidades

- Cadastrar livros digitais e físicos
- Consultar livro por ISBN
- Editar informações de um livro
- Remover livro
- Listar todos os livros
- Persistência de dados em JSON

## Conceitos aplicados

- Programação Orientada a Objetos (POO)
- Herança, encapsulamento e polimorfismo
- Manipulação de arquivos JSON
- Tratamento de erros com try/except
- Separação de responsabilidades em módulos

## Como executar

1. Clone o repositório
2. Execute o arquivo `main.py` com Python 3.10+

## Tecnologias

- Python 3.10+
